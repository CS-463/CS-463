# Kaggle Programming Project

Starter files for the Kaggle Programming Project. The project instructions and rubrics are in Canvas and in `Course_Documents/Grading_Rubrics.md`.

## What's here

| Folder | Contents |
| --- | --- |
| `Checkpoint_1/` | `checkpoint1.ipynb`, a skeleton for Checkpoint 1; `log.md`, a template for your experiment log; and `checkpoint_1_guidance.ipynb`, a reference notebook that walks through every Checkpoint 1 step on a different data set (it needs `checkpoint_1_helpers.py` in the same folder, and an internet connection the first time you run it, to download its data) |

## How to use it

Don't edit the files in `Project/` itself: your changes can conflict with the next `git pull`. Work in a folder of your own instead. Either way works:

- **Inside the course repo:** copy `Project/` to a new folder and rename *that copy* to something like `Project_YourName/`, and keep the same folder structure. Git leaves your copy alone, and the next `git pull` still delivers any new starter files into the *original* `Project/`. To summarize: Copy `Project/` -> rename the copy, *not* the original.
- **Outside the course repo:** If you're not relying on git pull to update course files, you can copy the starter files into any folder you like outside of the course repository.

The competition data isn't in this repo. Download `train.csv` and `test.csv` from the competition's **Data** tab (the link is in Canvas), and put them in a `data/` folder next to your kaggle project notebook. Each starter notebook explains the folder layout it expects.
